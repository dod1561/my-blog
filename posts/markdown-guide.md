## 인용문

> 단순함은 궁극의 정교함이다.
>
> 인용문 안에서도 **강조**와 `코드`를 쓸 수 있습니다.

## 코드 블록

```javascript
// 테마 전환
const next = currentTheme() === 'dark' ? 'light' : 'dark';
document.documentElement.dataset.theme = next;
```

```css
:root[data-theme="dark"] {
  --bg: #16181d;
  --text: #e3e5e8;
}
```

긴 코드는 블록 안에서만 가로로 스크롤되고, 페이지 전체는 넘치지 않습니다.
